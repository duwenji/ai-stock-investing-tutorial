# LLMの仕組みと得意/不得意

## この教材で身につくこと

- LLM（大規模言語モデル）の基本的な仕組み（次トークン予測）の理解
- 投資分析タスクにおけるLLMの得意分野・不得意分野の区別
- リアルタイム性が必要な処理をLLM単体に任せてはいけない理由の理解

## 概要

LLMは、直前までのテキストから次に来る単語（トークン）を確率的に
予測し続けることで文章を生成するモデルです。

学習時点までの大量のテキストからパターンを学びますが、
学習後に発生した出来事や、リアルタイムの数値は知りません。
インターネットや外部データベースへの常時接続機能も持ちません。

この仕組みを理解すると、LLMに「今日の株価を教えて」と聞くことが
なぜ危険かが分かります。LLMは答えを"知っている"のではなく、
もっともらしい文字列を生成しているだけだからです。

## 主要概念・パラメータ解説

### LLMの基本用語

| 用語 | 説明 |
|------|------|
| トークン化 | 文章を単語やサブワード単位の「トークン」に分割する処理 |
| 次トークン予測 | 直前の文脈から次のトークンを確率的に予測する仕組み |
| 学習データ | モデルの学習に使われたテキストの集合（コーパス） |
| 知識カットオフ | 学習データに含まれる情報の最新時点（詳細は次教材03） |
| コンテキストウィンドウ | 一度に処理できる入力+出力トークンの上限 |

### LLMが得意なタスク・不得意なタスク

投資リサーチの文脈では、次のように整理できます。

| LLMが得意なタスク | 具体例 | 理由 |
|--------------------|--------|------|
| 決算資料の要約 | 決算短信の要点を3行にまとめる | 自然言語のパターン認識に強い |
| 定性的な比較・説明 | 2社のビジネスモデルの違いを説明する | 意味理解・言語化が得意 |
| 分析用コードの生成 | 財務データ集計用Pythonスクリプトの作成 | コードの学習データが豊富 |
| 一般的な財務知識の解説 | PER・PBRとは何かを説明する | 一般知識として学習済み |

| LLMが不得意なタスク | 具体例 | 理由 |
|----------------------|--------|------|
| リアルタイム株価の取得 | 「今日の終値」を直接答えさせる | 学習データに存在せず、外部接続もない |
| 正確な数値計算の保証 | 複雑な財務モデルの計算結果 | 数値精度を保証する仕組みがない |
| 最新ニュースの把握 | 本日発表されたニュースの内容 | 知識カットオフ以降の情報は持たない |
| 事実の完全な正確性 | 個別銘柄の詳細な財務数値の暗唱 | ハルシネーションのリスクがある（次教材で詳説） |

## 実ソースコード（Python / プロンプト例）

### 悪い例: LLMに直接「今日の株価」を尋ねる

以下のプロンプトは、LLMが学習していない情報を求めており、
もっともらしい誤答（ハルシネーション）を誘発します。

```text
トヨタ自動車（7203）の本日の終値を教えてください。
```

```python
import anthropic

client = anthropic.Anthropic()

# 悪い例: LLMに直接リアルタイムの株価を尋ねている
response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=200,
    messages=[
        {
            "role": "user",
            "content": "トヨタ自動車（7203）の本日の終値を教えてください。",
        }
    ],
)

print(response.content[0].text)
```

### 良い例: 実データを取得してからLLMに渡す

株価データは外部APIから取得し、その結果をプロンプトに含めます。
株価データAPIとLLM APIの本格的な連携は、カテゴリ03で扱います。
ここでは最小限の例として、取得済みデータを渡す関数として示します。

```python
import anthropic


def get_stock_price(ticker: str) -> str:
    """株価データAPIからの取得結果を模した関数（詳細はカテゴリ03で解説）。"""
    return "7203.T: 2,845円（2026-07-18 15:00 JST 終値）"


client = anthropic.Anthropic()
price_info = get_stock_price("7203.T")

# 良い例: 取得済みの実データのみを根拠として渡す
response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=200,
    messages=[
        {
            "role": "user",
            "content": (
                "以下の株価情報のみを根拠に、簡潔な一文で説明してください。\n\n"
                f"{price_info}"
            ),
        }
    ],
)

print(response.content[0].text)
```

### 実行結果例

悪い例では、実際には存在しない数値がもっともらしく生成される
ことがあります（実行のたびに内容が変わる点にも注意）。

```text
トヨタ自動車の本日の終値は2,912円でした。
```

上記は実際の終値とは無関係な、生成されただけの数値です。
LLMは「知らない」とは言わず、自信ありげに答える点が危険です。

良い例では、渡した実データの範囲内でのみ回答が生成されます。

```text
2026年7月18日15時（JST）時点のトヨタ自動車（7203.T）の終値は2,845円でした。
```
