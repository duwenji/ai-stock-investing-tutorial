# 知識カットオフとリアルタイム性の問題

## この教材で身につくこと

- 「知識カットオフ」の意味と、投資分析における影響の理解
- リアルタイムデータが必須な用途かどうかを見極める判断軸の習得
- プロンプトに「いつ時点の情報か」を明示する設計パターンの理解

## 概要

LLMの学習データには「知識カットオフ」と呼ばれる、
学習データを収集した最新時点が存在します。

それ以降に発生した株価変動・決算発表・ニュースは、
モデルの知識には一切含まれません。また、LLM自体には
インターネットへの常時接続機能もありません。

株価やニュースは秒単位で変化します。LLMの記憶に頼った回答は、
知識カットオフの時点で情報が止まっているため、
現在の状況とは無関係な内容になっている可能性があります。

## 主要概念・パラメータ解説

### 知識カットオフのリスクを見極める視点

| 視点 | 確認すること |
|------|--------------|
| 時間依存性 | 対象データは時間の経過とともに変化するか |
| 更新頻度 | 秒単位・日次・年次など、どの頻度で変わるか |
| 情報の出所 | 渡す情報はプロンプトに含めるのか、LLMの記憶に頼るのか |
| 「as of」の明示 | 回答が「いつ時点」の情報かをプロンプトや出力に明示しているか |

「as of [日付]」のようにプロンプトで時点を明示すると、
LLMは渡された情報の鮮度を意識した回答をしやすくなります。
渡していない情報については、記憶に頼らず「不明」と
答えるよう合わせて指示することが重要です（前教材参照）。

### この用途はリアルタイムデータが必須か

| 用途 | リアルタイム性 | 理由 |
|------|-----------------|------|
| 株価の取得 | 必須 | 秒単位で変動し、記憶には存在しない |
| ニュースセンチメント分析 | 必須（最新ニュース） | 直近の報道内容が対象のため |
| 決算書の文言要約 | 不要（テキストを直接渡す場合） | 対象テキストをプロンプトに含めれば足りる |
| PER・PBRなど用語の説明 | 不要 | 一般知識として変化しない内容 |
| 銘柄の過去の業績推移の解説 | 不要（データを渡す場合） | 過去の確定データを渡せば再現できる |

## 実ソースコード（Python / プロンプト例）

「as of」を明示せず記憶に頼ろうとする悪い例と、
時点を明示したうえで取得済みデータを渡す良い例を比較します。

```text
最近の半導体関連銘柄の値動きはどうですか？
```

上記は「いつ時点か」が不明で、LLMが古い知識（知識カットオフ時点）を
現在の状況であるかのように回答してしまうリスクがあります。

```text
以下は2026年7月18日時点で取得した株価データです。
このデータのみを根拠に、半導体関連銘柄の値動きを説明してください。

---
（取得済みの株価データがここに入る）
---
```

Pythonでの実装例です。取得日時を明示したうえでデータを渡す、
最小限のパターンを示します。実際のAPI連携はカテゴリ03で扱います。

```python
import anthropic
from datetime import datetime, timezone

# 実際には株価データAPIから取得した結果を想定（カテゴリ03で詳説）
as_of = datetime(2026, 7, 18, 15, 0, tzinfo=timezone.utc)
price_data = "6758.T（ソニーG）: 3,120円（前日比 +1.8%）"

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=200,
    messages=[
        {
            "role": "user",
            "content": (
                f"以下は{as_of.isoformat()}時点で取得した株価データです。"
                "このデータのみを根拠に、値動きを1文で説明してください。\n\n"
                "---\n"
                f"{price_data}\n"
                "---"
            ),
        }
    ],
)

print(response.content[0].text)
```

### 実行結果例

時点を明示しない悪い例では、モデルの知識カットオフ時点の
一般論が返ってくることがあります。

```text
半導体関連銘柄は世界的な需要動向に左右されやすい傾向があります。
```

これは特定の時点の値動きには言及しておらず、
「最近の」という問いに実質的に答えられていません。

時点とデータを明示した良い例では、渡した情報に基づいた
具体的な回答が得られます。

```text
2026-07-18T15:00:00+00:00時点で、ソニーGは3,120円、
前日比+1.8%と上昇しています。
```

   同じ質問への回答がどう変わるか比較してください。
