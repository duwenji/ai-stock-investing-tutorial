# 金融商品取引法・投資助言業規制・免責事項の必要性

## この教材で身につくこと

- 金融商品取引法における「投資助言・代理業」の概念的な位置づけの理解
- 個人利用の学習ツールと、有償の投資助言サービスの違いの理解
- 出力に免責事項を含めるべき理由と、実装上の基本パターンの習得

## 概要

生成AIを使った株式投資リサーチツールを作る際には、
技術面だけでなく、法令・倫理面の境界線を理解しておく必要が
あります。

金融商品取引法では、特定の有価証券の価値等について、
口頭・文書等により投資判断の助言を行い、その対価を得る行為を
「投資助言・代理業」として位置づけ、登録を必要とする場合が
あります。

本教材のツール群は、個人の学習・自己のリサーチを目的とした
ものであり、第三者に対して報酬を得て個別の投資助言を
行うものではありません。この違いを明確に意識することが重要です。

> ⚠️ 本教材は法令の一般的な考え方を紹介する教育目的のものであり、
> 法的助言ではありません。実際のサービス提供や事業化を検討する
> 場合は、必ず弁護士・金融商品取引業に詳しい専門家に相談してください。

## 主要概念・パラメータ解説

### 投資助言・代理業とみなされうる行為の目安

| 区分 | 内容 | 登録の要否（一般論） |
|------|------|------------------------|
| 個人の学習・自己のリサーチ | 自分のためにAIで情報を整理・要約する | 通常は該当しない |
| 一般的な情報提供 | 銘柄を特定せず、一般的な用語・仕組みを解説する | 通常は該当しない |
| 特定銘柄への個別助言（無償・第三者向け） | 特定の有価証券について投資判断の助言を行う | 対価の有無等により判断が必要 |
| 特定銘柄への個別助言（有償） | 対価を得て特定の有価証券の投資判断を助言する | 投資助言・代理業の登録が必要となりうる |

この表はあくまで一般的な目安です。実際の該当性は
提供形態・対価の有無・対象者等によって個別に判断されます。

### 本教材の位置づけと利用範囲

| 観点 | 本教材のツール群 | licensed advisory serviceとの違い |
|------|-------------------|-------------------------------------|
| 目的 | 個人の学習・リサーチ支援 | 対価を得た第三者への投資助言 |
| 出力の性質 | 情報整理・要約・分析支援 | 個別銘柄の売買推奨を含みうる |
| 利用者 | 学習者本人 | 顧客・第三者 |
| 必要な免責 | 学習目的の明示 | 業法に基づく登録・体制整備 |

## 実ソースコード（Python / プロンプト例）

### 悪い例: 免責事項なしでレポートを出力する

```python
def generate_report(summary_text: str) -> str:
    """決算要約レポートを生成する（悪い例: 免責事項がない）。"""
    return f"【決算分析レポート】\n\n{summary_text}"
```

このような出力は、利用者がAI生成物であることや、
投資助言ではないことを認識しないまま利用してしまう
リスクがあります。

### 良い例: 出力に免責事項を明示する

```python
DISCLAIMER_NOTE = (
    "本レポートはAIによる情報整理・要約であり、投資助言ではありません。"
    "内容の正確性は保証されません。投資判断は一次情報を確認のうえ、"
    "自己責任で行ってください。"
)


def generate_report(summary_text: str) -> str:
    """決算要約レポートを生成する（良い例: 免責事項を明示）。"""
    return f"【決算分析レポート】\n\n{summary_text}\n\n---\n{DISCLAIMER_NOTE}"
```

レポート生成・ダッシュボード表示など、利用者の目に触れる
すべての出力機能で、この形式の免責表示を組み込んでください。
具体的な実装は
[カテゴリ06: Real World Examples](../06-real-world-examples/00-README.md)
で扱います。

### 実行結果例

悪い例の出力です。

```text
【決算分析レポート】

当第1四半期の売上高は1,250億円で、前年同期比+8.2%の増収でした。
```

良い例の出力です。

```text
【決算分析レポート】

当第1四半期の売上高は1,250億円で、前年同期比+8.2%の増収でした。

---
本レポートはAIによる情報整理・要約であり、投資助言ではありません。
内容の正確性は保証されません。投資判断は一次情報を確認のうえ、
自己責任で行ってください。
```
