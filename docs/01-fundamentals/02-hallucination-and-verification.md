# ハルシネーション対策・ファクトチェック手法

## この教材で身につくこと

- 金融データにおけるハルシネーション（事実と異なる生成）の具体例の理解
- 出典明示・グラウンディング・不確実性明示という3つの対策手法の習得
- 実データを根拠として渡すプロンプト設計の実践

## 概要

ハルシネーションとは、LLMが事実と異なる内容を、もっともらしく
生成してしまう現象です。投資分析では特に危険な性質を持ちます。

具体的には、次のような形で現れます。

- 存在しない売上高・利益額を数値として生成する
- 発生していないニュースをあったかのように説明する
- 銘柄コードや会社名を取り違える

前教材で見た通り、LLMは知識カットオフ以降の情報や、
学習していない数値を「知らない」とは言わず、
確率的にもっともらしい文字列を生成し続けます。
これがハルシネーションの根本原因です。

## 主要概念・パラメータ解説

| 手法 | 内容 | 効果 |
|------|------|------|
| 出典明示の要求 | 回答の根拠が「渡した情報」であることを明示させる | 記憶からの回答を防ぎやすくする |
| グラウンディング | 実際に取得した一次情報をプロンプトに含めて生成させる | 根拠のない数値の生成を防ぐ |
| 不確実性の明示指示 | 分からない場合は「不明」と答えるよう指示する | 自信ありげな誤答を減らす |

グラウンディングは、検索や取得（Retrieval）した情報を根拠に
生成させる手法の総称で、RAG（Retrieval-Augmented Generation）の
考え方の基礎にもなります。具体的なAPI連携はカテゴリ03・04で扱います。

## 実ソースコード（Python / プロンプト例）

### 悪い例: 根拠なく数値を尋ねる

```text
○○社（架空の例）の今期の売上高は？
```

このプロンプトは、モデルの記憶に頼った回答を誘発します。
実在の企業名に置き換えて試すと、もっともらしい誤った数値が
返ってくることがあります。

### 良い例: 取得済みの一次情報のみを根拠に要約させる

```text
以下は決算短信からの抜粋です。この内容のみを根拠に、
売上高と前年比を1文で要約してください。
本文に記載のない数値は絶対に補完しないでください。

---
（決算短信の抜粋テキストがここに入る）
---
```

「本文に記載のない数値は補完しない」という不確実性明示指示を
プロンプトに含めることで、記憶からの回答を抑制します。

Pythonでの実装例です。取得した決算資料のテキストを
`earnings_text` としてプロンプトに含める、単純なグラウンディングの
パターンを示します。

```python
import anthropic

# 実際には決算短信PDF等から抽出したテキストを想定（カテゴリ03で詳説）
earnings_text = (
    "当第1四半期の売上高は1,250億円（前年同期比+8.2%）となりました。"
    "主力事業であるクラウドサービスの契約数増加が寄与しています。"
)

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=300,
    messages=[
        {
            "role": "user",
            "content": (
                "以下は決算短信からの抜粋です。この内容のみを根拠に、"
                "売上高と前年比を1文で要約してください。"
                "本文に記載のない数値は絶対に補完しないでください。\n\n"
                "---\n"
                f"{earnings_text}\n"
                "---"
            ),
        }
    ],
)

print(response.content[0].text)
```

### 実行結果例

悪い例のプロンプトでは、実在の数値と無関係な回答が生成される
ことがあります。

```text
○○社の今期の売上高は約3,200億円と推定されます。
```

このような数値は、渡された情報が一切ない状態で生成された
ものであり、裏付けの取れない値です。

良い例では、渡したテキストの範囲内でのみ回答が生成されます。

```text
当第1四半期の売上高は1,250億円で、前年同期比+8.2%の増収でした。
```

## 演習課題

1. 「悪い例」のプロンプトを実際に試し、生成された数値が
   実在の企業の公表値と一致するか確認してください。
2. `earnings_text` の内容を書き換え、要約結果が入力テキストの
   範囲内に収まっているか確認してください。
3. 「不明な場合は『情報なし』と答えてください」という指示を
   プロンプトに追加し、応答の変化を観察してください。
