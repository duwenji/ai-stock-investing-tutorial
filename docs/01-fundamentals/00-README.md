# 01. Fundamentals - 生成AI基礎と投資適用の前提知識

このカテゴリでは、生成AI（LLM）を株式投資のリサーチに使う前に知っておくべき
前提知識を学びます。プロンプト設計やAPI連携などの実装に入る前に、
LLMの限界とリスクを正しく理解することが目的です。

LLMは万能ではありません。得意なことと不得意なことを区別できないまま
投資関連のツールを作ると、誤った情報を根拠に投資判断をしてしまう
リスクがあります。このカテゴリで、その境界線を明確にします。

## 学習目標

- LLMの仕組み（次トークン予測）と、投資分析における得意/不得意を理解する
- ハルシネーション（事実と異なる生成）のリスクと、その対策手法を身につける
- 知識カットオフとリアルタイム性の問題を理解し、データ取得の設計に活かす
- 金融商品取引法上の投資助言業との境界と、免責事項の必要性を理解する
