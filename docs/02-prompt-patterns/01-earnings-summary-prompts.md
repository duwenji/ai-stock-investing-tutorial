# 決算書要約プロンプト

## この教材で身につくこと

- 決算短信を構造化して要約するプロンプトの設計方法
- 出力スキーマを明示することで自由記述の要約を防ぐ手法
- 「本文にない数値は推測しない」ことをモデルに徹底させる指示の書き方

## 概要

決算短信は、売上高・利益・通期予想など重要な数値が長文の中に
散らばっています。LLMに要約させると、数値を丸めたり、前年同期比の
計算を誤ったりすることがあります。

出力フォーマットを指定しないプロンプトは、要約の粒度や項目が
実行のたびに変わり、後続処理（DB保存・表示）で扱いにくくなります。

## 主要概念・パラメータ解説

決算要約プロンプトを設計する際に、明示すべき要素は次の表の通りです。

| 要素 | 目的 | 具体例 |
|------|------|--------|
| 出力項目の固定 | 毎回同じ構造の要約を得る | 売上高・営業利益・純利益・通期予想修正・経営陣コメント |
| 単位の明示要求 | 数値の誤読を防ぐ | 「百万円単位、符号付きで記載」 |
| 前年同期比の算出元指定 | 勝手な暗算・丸めを防ぐ | 「本文に記載された比較値のみ使用」 |
| 情報がない場合の扱い | 空欄埋めのための推測を防ぐ | 「記載がない項目は『記載なし』とする」 |
| 出典範囲の限定 | モデルの一般知識混入を防ぐ | 「以下の決算短信本文のみを根拠にすること」 |

これらを守らないプロンプトは、モデルが本文にない情報を
補完してしまうリスクが高くなります。

## 実ソースコード（Python / プロンプト例）

### 悪い例

具体的な出力項目を指定していないため、要約の粒度が
実行のたびに変わり、数値を見落とすリスクもあります。

```text
この決算を要約してください。

（決算短信本文をここに貼り付け）
```

### 良い例

出力項目・単位・情報源の範囲を明示しています。
本文にない数値は「記載なし」とするよう指示しています。

```text
あなたは決算短信を要約するアシスタントです。
以下の【決算短信本文】のみを根拠に、次の項目を日本語の箇条書きで
出力してください。本文に記載のない数値は絶対に推測せず、
「記載なし」と書いてください。

出力項目:
- 売上高（金額と前年同期比%。単位は本文の表記に従う）
- 営業利益（金額と前年同期比%）
- 純利益（金額と前年同期比%）
- 通期業績予想の修正: 有/無、有りの場合は修正後の数値
- 経営陣コメントの要点（1〜2文、本文からの要約）

【決算短信本文】
{earnings_text}
```

### プロンプトテンプレートの適用

```python
EARNINGS_SUMMARY_PROMPT = """\
あなたは決算短信を要約するアシスタントです。
以下の【決算短信本文】のみを根拠に、次の項目を日本語の箇条書きで
出力してください。本文に記載のない数値は絶対に推測せず、
「記載なし」と書いてください。

出力項目:
- 売上高（金額と前年同期比%。単位は本文の表記に従う）
- 営業利益（金額と前年同期比%）
- 純利益（金額と前年同期比%）
- 通期業績予想の修正: 有/無、有りの場合は修正後の数値
- 経営陣コメントの要点（1〜2文、本文からの要約）

【決算短信本文】
{earnings_text}
"""


def build_earnings_summary_prompt(earnings_text: str) -> str:
    """決算短信本文を埋め込み、要約プロンプトを組み立てる。"""
    return EARNINGS_SUMMARY_PROMPT.format(earnings_text=earnings_text)


def call_llm(prompt: str) -> str:
    # 実装は 03-data-api/02-llm-api-integration.md 参照
    raise NotImplementedError


if __name__ == "__main__":
    text = "（実際には決算短信PDFから抽出したテキストを渡す）"
    prompt = build_earnings_summary_prompt(text)
    summary = call_llm(prompt)
    print(summary)
```

### 実行結果例

```text
- 売上高: 1,250百万円（前年同期比 +8.2%）
- 営業利益: 180百万円（前年同期比 +12.5%）
- 純利益: 120百万円（前年同期比 +5.1%）
- 通期業績予想の修正: 有（売上高予想を4,900百万円→5,050百万円に上方修正）
- 経営陣コメントの要点: 国内主力事業の受注が想定を上回り、下期も
  堅調な需要が見込まれるとしている。
```
