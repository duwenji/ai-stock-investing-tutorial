# レポート自動生成プロンプト

## この教材で身につくこと

- 複数の検証済みデータを統合してレポートを生成するプロンプト設計
- 「事実」と「AIによる考察」を出力内で明確に分離させる指示の書き方
- 免責事項をレポートに自動付加する実装パターン

## 概要

これまでの教材で、決算要約・ニュースセンチメント・スクリーニング
結果という3種類の構造化データを作る方法を学びました。

この教材では、それらのデータを1つのレポート生成プロンプトに
統合します。レポート生成は自由記述の分量が多くなるため、
モデルが事実と意見を混同しやすく、投資助言と誤解されるリスクが
最も高い工程です。出力の構造とルールを明示することが重要です。

## 位置づけ

この教材は02-prompt-patternsカテゴリの最終教材です。
01〜03で作った構造化データ（決算要約・センチメント・スクリーニング
結果）を入力として組み合わせる、統合的な使い方を示します。

次の03-data-apiカテゴリでは、ここで使ったプロンプトを実際の
LLM APIで動かす方法を学びます。

## 主要概念・パラメータ解説

| 要素 | 目的 | 具体例 |
|------|------|--------|
| 入力データのラベル化 | どのデータがどの主張の根拠か追跡可能にする | 「【決算データ】」「【ニュース分析結果】」等の見出しを付けて渡す |
| セクション構成の指定 | 事実と考察を混在させない | 「事実」「AIによる考察」を別見出しで出力させる |
| 出典の明示要求 | 主張の根拠を検証可能にする | 「各事実の末尾に、根拠となった入力データ名を記載」 |
| 免責文の自動付加 | 投資助言と誤解されることを防ぐ | 出力の最後に固定の免責文を必ず含めるよう指示 |
| 未知情報の扱い | 入力にない情報の創作を防ぐ | 「入力データにない情報は記載しない」 |

## 実ソースコード（Python / プロンプト例）

### 悪い例

構造の指定がなく、モデルが自由に意見を述べられる状態です。
まるで投資アドバイザーであるかのような断定的な文章を
生成してしまうリスクがあります。免責文の指示もありません。

```text
この銘柄についてのレポートを書いてください。
決算とニュースの情報は次の通りです。

（決算要約とニュース分析結果をここに貼り付け）
```

### 良い例

出力セクションを明示し、事実と考察を分離させています。
各事実の出典を明記させ、末尾に免責文を必ず含めるよう
指示しています。

```text
あなたは株式リサーチレポートを作成するアシスタントです。
以下の【入力データ】のみを根拠に、次の構成でレポートを
日本語で作成してください。入力データにない情報は記載せず、
断定的な売買推奨の表現は使わないでください。

出力構成:
1. 事実
   - 入力データから読み取れる客観的事実を箇条書きで記載
   - 各項目の末尾に (出典: データ名) の形式で出典を明記
2. AIによる考察
   - 上記の事実から考えられる留意点を記載
   - 「〜と考えられる」等、断定を避けた表現を使う
3. 免責事項
   - 「本レポートはAIによる情報整理であり、投資助言では
     ありません。投資判断は自己責任で、一次情報の確認のうえ
     行ってください。」という文を必ずそのまま記載する

【入力データ】
- 【決算データ】
{earnings_summary}
- 【ニュース分析結果】
{news_sentiment}
- 【スクリーニング結果】
{screening_result}
```

### プロンプトテンプレートの適用

```python
REPORT_PROMPT = """\
あなたは株式リサーチレポートを作成するアシスタントです。
以下の【入力データ】のみを根拠に、次の構成でレポートを
日本語で作成してください。入力データにない情報は記載せず、
断定的な売買推奨の表現は使わないでください。

出力構成:
1. 事実
   - 入力データから読み取れる客観的事実を箇条書きで記載
   - 各項目の末尾に (出典: データ名) の形式で出典を明記
2. AIによる考察
   - 上記の事実から考えられる留意点を記載
   - 「〜と考えられる」等、断定を避けた表現を使う
3. 免責事項
   - 「本レポートはAIによる情報整理であり、投資助言では
     ありません。投資判断は自己責任で、一次情報の確認のうえ
     行ってください。」という文を必ずそのまま記載する

【入力データ】
- 【決算データ】
{earnings_summary}
- 【ニュース分析結果】
{news_sentiment}
- 【スクリーニング結果】
{screening_result}
"""


def build_report_prompt(
    earnings_summary: str, news_sentiment: str, screening_result: str
) -> str:
    """検証済みの各データをラベル付きで結合し、レポート生成プロンプトを組み立てる。"""
    return REPORT_PROMPT.format(
        earnings_summary=earnings_summary,
        news_sentiment=news_sentiment,
        screening_result=screening_result,
    )


def call_llm(prompt: str) -> str:
    # 実装は 03-data-api/02-llm-api-integration.md 参照
    raise NotImplementedError


if __name__ == "__main__":
    # 各データは 01, 02, 03 の教材で作成したプロンプトの出力結果を想定
    earnings = "売上高: 1,250百万円（前年同期比 +8.2%） 他"
    sentiment = "sentiment: ポジティブ, confidence: 0.72"
    screening = "PER15倍以下・配当利回り3%以上でヒットした銘柄一覧"

    prompt = build_report_prompt(earnings, sentiment, screening)
    report = call_llm(prompt)
    print(report)
```

### 実行結果例

```text
# 1. 事実

- 当期売上高は1,250百万円で、前年同期比+8.2%であった (出典: 決算データ)
- 直近ニュースの短期株価インパクト判定はポジティブ、確信度0.72
  であった (出典: ニュース分析結果)
- PER15倍以下・配当利回り3%以上の条件でスクリーニングした結果、
  対象銘柄が抽出された (出典: スクリーニング結果)

# 2. AIによる考察

- 売上・利益の増加とポジティブなニュース判定が重なっており、
  短期的には市場の反応が良好である可能性が考えられる。
- ただし確信度は0.72であり、判定には一定の不確実性が
  残っている点に留意が必要と考えられる。

# 3. 免責事項

本レポートはAIによる情報整理であり、投資助言ではありません。
投資判断は自己責任で、一次情報の確認のうえ行ってください。
```

## 演習課題

1. 「悪い例」のプロンプトで生成されるレポートに、断定的な
   売買推奨の表現が混入しうる箇所を予想してください。
2. 「AIによる考察」セクションの文末表現（「〜と考えられる」等）を
   強制するチェック処理をPythonで追加してください。
3. 免責文が出力に含まれなかった場合に検知する簡単な検証関数を
   書いてください。
