# 保有銘柄ポートフォリオタブの表を1つに簡潔化

## 背景・課題

`app/app_tabs/portfolio_tab.py` の「保有銘柄ポートフォリオ」タブには、現在2つの表が並んでいる。

1. 編集可能な `st.data_editor` テーブル（銘柄コード・銘柄名・保有株数・取得単価。追加/編集/削除/保存を担う）
2. 「銘柄詳細を見る」の一覧テーブル（保有銘柄ごとに行を並べ、各行に銘柄コード・銘柄名・「詳細」ボタンを表示し、クリックすると銘柄詳細ダイアログを開く）

同じ保有銘柄の情報が2つの表に重複して表示されており、画面が冗長。1つの表にまとめて簡潔にしたい。

## 方針

- 編集可能テーブル（1）はそのまま維持する。保有銘柄の追加・編集・削除・保存という主機能を持つため、これを唯一の「表」として残す。
- 「銘柄詳細を見る」テーブル（2）は廃止する。
- 代わりに、詳細を見たい銘柄を選ぶための「セレクトボックス1つ＋『詳細』ボタン1つ」を設置する。選択肢は現在の保有銘柄一覧（`ticker + 銘柄名`）から作る。ボタン押下で既存の `show_stock_detail_dialog(ticker, name)` を呼び出す（ダイアログ表示のロジックは変更しない）。

## 変更範囲

`app/app_tabs/portfolio_tab.py` の `render_portfolio_tab()` 内、107〜117行目付近（`if holdings:` ブロック、テーブル形式のループ表示部分）のみ。
それ以外（データ保存処理、AIレビュー生成処理、参照ニュース表示など）は変更しない。

## 影響を受けないもの

- `portfolio_management/storage.py`（保存・読込ロジック）
- `holdings.json` のデータ構造
- 他タブ・他モジュール

## テスト

このタブはStreamlit UIのため自動テストは対象外。実装後に `streamlit run app.py` を起動し、保有銘柄タブで以下を目視確認する。

- 表が1つだけになっていること
- セレクトボックスで銘柄を選び「詳細」ボタンを押すと、従来通り詳細ダイアログが開くこと
- 編集・保存・レビュー生成など既存機能に影響がないこと
