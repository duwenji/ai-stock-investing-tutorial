# リスク評価・分散

## この教材で身につくこと

- ボラティリティ（年率換算）をpandasで計算する方法
- 銘柄間の相関係数を `DataFrame.corr()` で算出する方法
- リスク指標をLLMに解説させる際、個人向け助言と誤解されない伝え方

## 概要

複数銘柄を保有していても、値動きが似た銘柄ばかりでは分散効果が
限定的になります。ボラティリティと相関係数は、この「分散できているか」を
定量的に把握するための代表的な指標です。

これらの指標は数式で明確に定義されており、Pythonでの計算は決定的です。
LLMの役割は、計算結果の数値が何を意味するかを平易な言葉で説明することに
限定します。

## 主要概念・パラメータ解説

### 代表的なリスク指標

| 指標 | 計算方法 | 何を示すか |
|------|----------|-----------|
| ボラティリティ | 日次リターンの標準偏差 × √250 | 価格変動の大きさ（年率）。高いほど値動きが荒い |
| 相関係数 | `DataFrame.corr()`（-1〜1） | 銘柄間の値動きの連動性。1に近いほど同じ動きをする |
| 最大ドローダウン | 累積リターンのピークからの最大下落率 | 過去に発生した最大の下落幅 |

年率換算に用いる「√250」は、1年間の営業日数（約250日）の平方根です。
日次の標準偏差を年率スケールに合わせるための係数です。

### 相関係数の目安

| 相関係数の範囲 | 傾向 |
|---------------|------|
| 0.7以上 | 非常に強い正の連動。分散効果は限定的な可能性がある |
| 0.3〜0.7 | 中程度の連動 |
| -0.3〜0.3 | 連動が弱い、または無関係 |
| -0.3以下 | 逆方向の値動きの傾向がある |

これらはあくまで一般的な目安であり、期間や市場環境によって変動します。

## 実ソースコード（Python / プロンプト例）

### ボラティリティと相関係数の計算

```python
import numpy as np
import pandas as pd
import yfinance as yf

TRADING_DAYS_PER_YEAR = 250


def fetch_daily_returns(tickers: list[str], period: str = "1y") -> pd.DataFrame:
    """複数銘柄の日次リターンをまとめたDataFrameを返す。"""
    prices = yf.download(tickers, period=period)["Close"]
    returns = prices.pct_change().dropna()
    return returns


def compute_risk_metrics(returns: pd.DataFrame) -> tuple[pd.Series, pd.DataFrame]:
    """年率ボラティリティと相関係数行列を計算する。"""
    annualized_vol = returns.std() * np.sqrt(TRADING_DAYS_PER_YEAR)
    corr_matrix = returns.corr()
    return annualized_vol.round(4), corr_matrix.round(2)
```
