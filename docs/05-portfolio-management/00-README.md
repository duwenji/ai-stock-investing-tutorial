# 05. Portfolio Management - ポートフォリオ管理・バックテスト

このカテゴリでは、単一銘柄ではなく**複数銘柄からなるポートフォリオ**を対象に、
生成AIを分析支援ツールとして活用する方法を学びます。

04-analysis-agentsで学んだ「Pythonが数値を計算し、LLMはその数値を解釈・要約する」
という原則を、ポートフォリオ全体の分析に拡張します。銘柄の売買判断や
資産配分の指示をAIに行わせることはありません。

## 学習目標

- 保有銘柄一覧から構成比・損益をPythonで集計し、LLMに自然言語で要約させる
- ボラティリティ・相関係数などのリスク指標をPythonで計算し、LLMに解説させる
- ルールベース戦略のバックテストをPythonで実装し、結果をLLMに解説させる
- 複数銘柄・業種間の値動きの時間差（リード・ラグ）をシフト相関で検出する
- （発展）周期分解（ウェーブレット）により、周期の長さごとのリード・ラグとその確からしさを分析する

## 学習の進め方

01 → 05 の順に進めることを推奨します（05は発展・オプションのため、時間が限られる場合は04までで次のカテゴリに進んでも構いません）。

このカテゴリの5教材はすべて、次の順序で処理を行う共通パターンに従います。

1. `yfinance` などから価格・財務データを取得する
2. `pandas` で構成比・リスク指標・バックテスト結果などの数値を計算する
3. 計算済みの数値をプロンプトに埋め込み、LLMに自然言語での要約・解説を依頼する

LLMに数値の計算そのものを行わせない理由は、04-analysis-agentsの
テクニカル分析エージェント（[04-analysis-agents/02](../04-analysis-agents/02-technical-analysis-agent.md)）
で学んだ通り、LLMは算術を誤る可能性があるためです。この原則は
ポートフォリオ規模の分析でも変わりません。
