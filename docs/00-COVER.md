# 生成AI活用 株投資リサーチ・ツール構築チュートリアル - 全体像

## このチュートリアルで身につくこと

- 株式投資に生成AIを使う際のLLMの得意/不得意とリスクの理解
- 決算要約・ニュース分析・銘柄スクリーニングの **プロンプト設計力**
- 株価データAPIとLLM APIをPythonで連携させる実装力
- ファンダメンタル/テクニカル分析エージェントと **MCPサーバー** の構築力
- AIを活用したポートフォリオ分析・リスク評価・バックテスト自動化の手法
- 日次レポートツールやスクリーニングダッシュボードなど実践的なツール構築力

## 対象読者

- Pythonでの開発経験があるエンジニア/開発者
- 株式投資の基礎知識はあるが、生成AIを使った分析ツール構築は未経験の方
- ChatGPT/ClaudeなどのAPIを実務的なワークフローに組み込みたい方

> ⚠️ 本教材は投資助言を目的としたものではありません。[DISCLAIMER.md](../DISCLAIMER.md) を必ずお読みください。

```

             LLMの特性・ハルシネーション対策・知識カットオフ・法令倫理

STEP 2 ──→ Prompt Patterns（4教材）
             決算要約・ニュース分析・スクリーニング・レポート生成

STEP 3 ──→ Data & API（4教材）

STEP 4 ──→ Analysis Agents（4教材）
             ファンダメンタル/テクニカル/ニュース分析エージェント・MCPサーバー構築

STEP 5 ──→ Portfolio Management（3教材）
             AIポートフォリオ分析・リスク評価・バックテスト自動化

STEP 6 ──→ Real World Examples（3教材）
             日次レポートツール・スクリーニングダッシュボード・統合アドバイザー構築演習
```

## 前提知識

| 知識 | 要否 |
|------|------|
| Python基本文法（関数・クラス・パッケージ管理） | ✅ 必須 |
| REST API・JSONの基本理解 | ✅ 必須 |
| 株式投資の基礎用語（PER, PBR, 決算短信等） | 🔶 推奨 |
| コマンドライン操作 | 🔶 推奨 |

## 本チュートリアルの特徴

1. 「良い例」と「悪い例」の対比でプロンプト・コードの理解が深まる
2. 全コードがコピペ可能で、実際のAPIキーを設定すればすぐ動作確認できる
3. プロンプト設計だけでなく、MCPサーバーによる本格的なツール構築まで学べる
4. 投資助言との線引き（免責事項・一次情報での検証）を各所で明示する
