# 03. Data & API - データ取得・API連携

このカテゴリでは、実際の株価データをPythonで取得し、LLM APIと
連携させる実装方法を学びます。

01-fundamentalsで学んだ通り、LLMは学習データの知識カットオフ以降の
株価・ニュースを知りません。02-prompt-patternsで設計したプロンプトも、
実データをPythonから渡さなければ機能しません。このカテゴリでは、その
「データ取得 → LLMに渡す → 構造化された結果を受け取る」という一連の
実装を、コストとレート制限の管理まで含めて身につけます。

## 学習目標

- `yfinance` を使って株価・財務データをPythonで取得できる
- Claude APIとOpenAI APIをPythonから呼び出し、応答を取得できる
- 自由文ではなく構造化出力（JSON/Tool use）で解析可能な結果を得られる
- トークン数・API呼び出し回数からコストを見積もり、レート制限に対処できる

## 4つの構成要素

このカテゴリの4教材は、次の順で1つのパイプラインを組み立てます。

| 要素 | 役割 |
|------|------|
| 株価API取得 | 生きた市場データをPythonのオブジェクトとして取得する |
| LLM API呼び出し | 取得したデータやプロンプトをLLMに送信し、応答を受け取る |
| 構造化出力 | LLMの応答を壊れにくいJSON形式として確実にパースする |
| レート制限・コスト管理 | 大量の銘柄・呼び出しでも破綻しない運用にする |

## 学習の進め方

01 → 04 の順に進めることを推奨します。

02で定義する `call_llm(prompt: str) -> str` は、以降の教材
（03の構造化出力、04のバックオフラッパー、04-analysis-agentsの各エージェント）
で共通して使われる基本関数です。まずこの関数の役割を理解してください。

すべてのAPIキーはプレースホルダー（`YOUR_API_KEY`）と環境変数読み込みの
コードで示します。実際のキーをソースコードに直接書き込まないでください。
