# 04. Analysis Agents - 分析エージェント構築

このカテゴリでは、単発のプロンプト呼び出しから一歩進み、
データ取得とLLM推論を組み合わせた「エージェント」を構築します。
最終的には、株式データをMCP（Model Context Protocol）サーバーとして
公開し、任意のMCP対応AIクライアントから呼び出せる形にします。

## このカテゴリで学ぶこと

これまでのカテゴリでは、1回のAPI呼び出しでプロンプトに応答を得る
方法を学びました。ここでは、次のような複数ステップを自動で
実行する仕組みを作ります。

1. `yfinance` などで実データを取得する
2. 取得したデータをもとにプロンプトを組み立てる
3. `call_llm` / 構造化出力パターンでLLMに推論させる
4. 結果を構造化データとして返す、または集計する

さらに、この一連の処理を **MCPサーバー** というツールの形で
公開する方法も学びます。MCPサーバーを使うと、Claude Desktopや
Claude CodeなどMCP対応クライアントから、自然言語の質問に応じて
自動的に株価取得ツールが呼び出されるようになります。

## 学習目標

- yfinanceのデータとLLMを組み合わせ、ファンダメンタル分析を
  自動化するエージェントを構築できる
- pandasで計算したテクニカル指標をLLMに解釈させるエージェントを
  構築できる
- 複数のニュース記事を個別にセンチメント分析し、結果を集計する
  エージェントを構築できる
- 株式データをMCPサーバーのツールとして公開し、MCP対応クライアント
  から呼び出せるようにする
